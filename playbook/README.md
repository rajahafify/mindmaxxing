# Persuasion & Branding Playbook

A running log of persuasion, sales, and branding tactics found online.

## How it's organized

One file per category. Each tactic is one entry using the template below.

| File | What goes here |
|---|---|
| [persuasion.md](persuasion.md) | Psychology and influence principles (reciprocity, anchoring, social proof...) |
| [sales.md](sales.md) | Selling, closing, objection handling, offers, pricing |
| [copywriting.md](copywriting.md) | Hooks, headlines, ad and landing-page copy patterns |
| [branding.md](branding.md) | Positioning, identity, voice, storytelling, audience building |
| [negotiation.md](negotiation.md) | Deal-making and bargaining tactics |
| [business.md](business.md) | Company building, team roles, operations, strategy, productivity |
| [social.md](social.md) | Conversation, charisma, everyday communication |
| [dating.md](dating.md) | Flirting, attraction, dating dynamics |
| [inbox.md](inbox.md) | Quick dumps of links not yet sorted or written up |

New categories can be added any time as a new file plus a row here.

## Entry template

```markdown
### Tactic name
- **Tags:** #tag1 #tag2
- **What it is:** one or two sentences
- **Why it works:** the psychology behind it
- **Example:** a concrete use (script, ad, brand)
- **How I'd use it:** personal application ideas
- **Watch out:** when it backfires or crosses into manipulation
- **Source:** [title](link), date found
```

Tags make it easy to cross-reference (e.g. #pricing, #scarcity, #email, #b2b).
